# 초록 단서 — 우리 마을 환경 미스터리

초등 4~5학년, 3~5인 모둠의 근거 기반 환경 탐구 웹앱입니다.

## 실행
Node.js 24 이상에서 `npm start`를 실행합니다. 기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. 외부 패키지 설치는 필요 없습니다. `npm test`는 격리된 임시 DB에서 교사 계정, 3/4/5명 참여, 단서 분배, 권한, 제출과 결과 공개를 검증합니다.

교사는 첫 화면에서 계정을 만들고 수업을 생성합니다. 모둠 대표는 수업 코드와 인원을 입력하고, 다른 학생들은 생성된 모둠 코드로 참여합니다. 서로 다른 기기 또는 브라우저 프로필을 사용하세요. 한 브라우저에서는 하나의 참여 세션을 사용합니다. 같은 네트워크에서 접속 가능한 서버 주소를 사용하세요.

계정, 세션, 수업, 답변은 `.data/game.db`에 보관합니다. 운영 시 이 파일을 영속 볼륨에 두고 백업하세요. `DB_PATH`로 파일 위치를 변경할 수 있습니다. 상태는 3초마다 갱신합니다. 서버 재시작 후에도 결과가 유지됩니다.

## 범위와 후속 확인
- 비밀번호는 salt와 scrypt 해시로 보관합니다. 학생 단서와 해설은 서버가 참여 권한과 제출 상태에 맞춰 반환합니다.
- 타이머는 안내용이며 만료 시 자동 제출하지 않습니다. 교사의 전체 이동은 추리 단계에서 멈추고, 모둠 대표의 제출 후에 해설이 공개됩니다.
- 첫 사건과 단서는 고정입니다. 3~5명 모두 다섯 단서를 분배받습니다. 추가 아이디어와 실천 행동은 모둠 답변에 저장됩니다.
- 공개 서비스 배포 전 HTTPS, 로그인 시도 제한, 비밀번호 재설정, 계정/수업 삭제와 보관 정책을 추가해야 합니다. 현재 버전은 수업 시범 운영용입니다.
- 실제 학생 읽기 속도와 40분 수업 적합성, 브라우저 접근성은 현장 사용 시험이 필요합니다. 무더위 사건과 듣기 기능은 포함하지 않습니다.

## Vercel 배포

Vercel Functions는 로컬 SQLite 파일을 영속 보관하지 않습니다. 배포 환경에서는 Turso 데이터베이스를 사용합니다. 로컬에서도 동일한 libSQL 클라이언트를 사용해 파일 기반 SQLite를 읽습니다.

1. Turso에서 데이터베이스를 생성하고 URL과 인증 토큰을 확보합니다.
2. Vercel 프로젝트의 Environment Variables에 `TURSO_DATABASE_URL`과 `TURSO_AUTH_TOKEN`을 Production 및 Preview 용도로 설정합니다. 값은 채팅이나 Git에 올리지 마세요.
3. Node.js 24.x, Framework Preset: Other, Build Command: `npm run build`, Output Directory: `public`을 사용합니다. `vercel.json`에 설정되어 있습니다.
4. 저장소 루트에서 `npx vercel login` 후 `npx vercel --prod`를 실행합니다. 이 환경의 CLI 설정 경로는 `/workspace/.vercel-cli`이므로 `--global-config /workspace/.vercel-cli`를 추가합니다.
5. 배포 주소에서 교사 계정 생성 → 수업 생성 → 서로 다른 브라우저/기기로 학생 참여 → 단서 확인 → 제출 → 교사 결과 조회를 검증합니다.

현재 로컬 통합 테스트는 통과했지만 원격 Turso 연결과 Vercel 배포는 인증·네트워크 설정 후 별도로 검증해야 합니다. 서버리스 동시 요청에 대한 모둠 가입의 원자적 처리 및 로그인 요청 제한은 공개 운영 전 보강이 필요합니다.
